# Danish Ali Bajwa — Professional Portfolio

A responsive, static portfolio with a professional portrait, biography, venture showcases, expertise, trading background, and a searchable library of 111 distinct titles found in Amazon listings.

Live website: https://danishalibajwa.github.io/

## Updating the website

- Edit `index.html` for biography, ventures, skills, or contact details.
- Edit `books.json` to add or update books. Each entry contains `title`, `url`, and `image`.
- Edit `style.css` for appearance and responsive layout.
- Upload changed files to the main branch. GitHub Pages republishes automatically.

The site requires no paid services or build step. Book cover images load from the public Amazon image URLs in the catalogue. Contact buttons open the visitor's email application.
